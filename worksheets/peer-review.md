# Worksheet — Peer Review of a Data Story

Swap briefs. 20 minutes. Read the brief **before** you look at the charts —
if the claim does not survive that, the charts are decoration.

## 1. The claim

> Write your partner's claim in your own words, in one sentence.

If you cannot, the brief does not have one. That is the finding.

## 2. Is the claim supported?

| | Check | Y/N |
|---|---|---|
| 2.1 | Every number in the claim appears in a chart or table | |
| 2.2 | The charts show what the text says they show | |
| 2.3 | The sample size is stated | |
| 2.4 | An alternative explanation is named and tested | |
| 2.5 | The limitation is in the claim, not buried at the end | |

## 3. Chart hygiene

| | Check | Y/N |
|---|---|---|
| 3.1 | No truncated y-axis on a comparison chart | |
| 3.2 | Axes are labelled with units | |
| 3.3 | Colour carries meaning, not decoration | |
| 3.4 | The chart type suits the question | |
| 3.5 | Missing data is visible somewhere | |

**3.1 is the one to check hardest.** A bar chart starting at 60 instead of 0
turns a 6-point gap into an apparent collapse, and every number on it stays
true. It is the commonest honest-looking lie in data communication.

**3.5 catches the commonest omission.** If no chart shows what is missing, ask
how much is missing. The answer is rarely zero and is rarely evenly spread.

## 4. The two questions

### Does the evidence support the claim, or merely accompany it?

> A chart next to a claim is not evidence for it. Chart 3 in the worked
> example earns its place because it rules out a specific alternative —
> "a few very low scores" — that would otherwise explain the gap.

### What would change your mind?

> Ask your partner. If there is no answer, the claim is not falsifiable and
> the brief is advocacy.
>
> Good answer: *"If the missing Madurai grades turned out to be a clerical
> batch unrelated to performance, I would report 6.6 as an estimate rather
> than a lower bound."*

## 5. One thing to fix

> The single change that would most improve the brief. One sentence. Be
> specific enough that they could act on it today.

---

## Giving the feedback

1. **Quote before you judge.** "The claim says 'significantly lower' but no
   test is reported" beats "it's vague".
2. **Say what would fix it.**
3. **Separate fact from preference.** "The y-axis is truncated" is a fact.
   "I'd have used a dot plot" is a preference — say it, but label it.
